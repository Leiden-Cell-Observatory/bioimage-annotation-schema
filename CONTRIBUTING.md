# Contributing

Proposals, questions and implementations are welcome: open an issue or a pull request.

- Change the LinkML file only, then run `pixi run gen` and `pixi run test` and commit
  the generated files with it.
- Every change gets a line in `CHANGELOG.md`.
- A new field needs a description and, where one exists, a mapping to MIFA or schema.org.

## Authorship

Anyone who contributes substantially to a release (fields, rules, mappings,
documentation, examples, or an implementation in a tool) is listed in
`CITATION.cff` and `.zenodo.json`, and so becomes an author of that release's DOI.
